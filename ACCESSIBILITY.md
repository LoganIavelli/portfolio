# Accessability Breakdown
While my score was a 100/100 for accessability, I would like to add that my website is still far from finished and I am sure that this score will drop as I begin adding more content. With that in mind, I wanted to use this to address how I will be moving forward with building on my portfolio site to adhere best to accessability rules and standards. For once, checking with PageSpeed insights after significant changes have been made. This is so that I can then edit anything after publishing to iron out problems instead of letting them build. Additionally, beginning to use uniform image sizing and formats for simplicity.
